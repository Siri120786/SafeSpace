# AI Companion — localization drafts

Preserved from the legacy AI Companion draft before `stash@{0}` is dropped.
These strings were the old fallback reply ("I am here for you…") that the
first version of the Edge Function returned when the model was unavailable.
That fallback was removed on purpose: the current function never shows a
fake reply, and returns `ai_unavailable` instead.

- **Source:** `stash@{0}` (03782df), `supabase/functions/ai-companion/index.ts`, `fallbackMessages`
- **English original (for reference):** "I am here for you. Thank you for sharing how you feel. How can I best support you right now?"
- Each translation below is copied exactly from the source, byte for byte: same script, spelling and punctuation. Nothing has been corrected or re-translated.

> **Not approved for production, crisis support, or clinical communication.**
> Every entry is an unreviewed draft and needs review by a native speaker before any use.
